05Iconography direction

Construction. 20px grid, 1.5px stroke, square caps and miter joins. Corners are chamfered (45° cut, 2px) not rounded — that's the industrial tell. Filled shapes only for status dots and the R/W mode glyph.
Sets. Objects (outpost, hand, relay, manifest, shift, orders) · Actions (found, clear, revoke, open, close, edit, commit) · Sources (one per connector: notion, git, discord, file). Source icons are the connector's own mark only where its brand policy allows; otherwise a monoline stand-in.
Mode glyph. Read = outlined chamfered square with a dot. Write = the same square filled. On a chip the mode is written out ("read" / "write") under the tool name; color alone never carries mode.
Lane markers. Direction = a chevron pair at the reading end, never an arrowhead triangle. Paired relays show chevrons at both ends, offset ±3px from the lane center so each half is hit-testable.

06Motion spec

Motion is proof, not theater: state transitions animate only what the last sortie actually recorded. Two loops exist. Idle is a slow one-unit bob with a visor blink every few seconds, so a hand reads as present, not frozen. Working is the only loop that carries meaning: glow, breathe, arms alternating, head nod — and it plays only while a sortie is provably open. Done and failed are one-shot transitions. Reduced motion: every animation collapses to a 120ms opacity change; packets render as a static dot at the reading end; bob and blink stop.

07Character rig

Quantized vector, not pixel art. One SVG symbol on a 24×32 unit grid, every shape a grid-snapped rect, shape-rendering: crispEdges, rendered only at integer scales (1×/2×/4×). Reads as a sprite, ships as vector, recolors through CSS variables. The register is the slim chrome android: a domed head with two small antennae and a full glowing visor, ball-joint shoulders, a narrow segmented torso carrying a core trace, thin articulated arms and long legs with lit joints, chrome plating over a dark inner frame. Light is state: visor, joints and trace glow only while the hand is provably working. Nothing organic, nothing armed.

Customization model. A hand is assembled from five layers — body (pose) · head · shoulder · trace · accessory — over two metal tints. Chosen parts express persona: tintHue · trimHue · head · trace. Derived parts express config and cannot be picked: shoulder (write clearance), accessory (relay reads / repo access), pose + glow (run state). So two hands with the same taste still look different if one can write and the other can't — the design carries the permission model. 3 heads × 6 traces × 2 tints ≈ any team is distinguishable at 1×; new heads and traces are one symbol each.
Why this silhouette. Narrow torso, long legs and thin limbs give the android read at 1× where a wide-shouldered block reads as a mech. Ball-joint shoulders and single-unit lit joints make the limbs articulate. A full glowing visor instead of eyes keeps it a device with no face — expression is whether it's lit. Chrome tints stay near-neutral so the glow is always the loudest thing on the figure.
Overseer: its own hero rig. A dedicated 48×64 symbol — same unit size, twice the resolution — heavier than any hand: crest blades, bone face plate with vent slits, chest intakes, a large frame trace, backpack stabilizers, skirt armor, gauntlets, knee guards, wide feet. Pure greys — no tint allowed — with the same state-owned glow. It is the only figure with a second grid and the only one built like a mech rather than an android; that contrast is the hierarchy. Sits in the octagon core at map center; never on a card, never on an outpost. v0 geometry — to be re-proportioned toward the slimmer hand register next.
Sizes. Hands: 1× (24×32) on cards, 2× (48×64) in the panel header, 4× (96×128) in the commission editor. Overseer: 2× (96×128) in the map core, 4× (192×256) in its report panel; never 1×. Never fractional. Below 1× a hand card shows the head unit only (y1–9) as a 14×9 chip.
Implementation: one <symbol> each for body, glyph, accessory in a shared sprite, three <use> per hand, palette as inline CSS vars from commission.rig = { tintHue, trimHue, head, trace }; shoulder and accessory are computed from the commission's allowlist and the outpost's orders, highlight and frame come from the theme, pose and glow from run state. Overseer uses #ow-overseer with the fixed achromatic set. Both rigs are v0 proportion studies, not final drawings.

Hybrid (C). B for hands in the panel and commission editor where fidelity pays off; A for the 1× map card, the world disc, and every mark and glyph where a 24px sprite would be mush anyway. Two authoring paths, one palette contract. Cost: the two renderings must agree on silhouette, so A is derived from B by quantization — exactly the trace pipeline above, run as a build step.
What doesn't change. commission.rig = { tintHue, trimHue, head, trace }, state-owned glow, integer scaling, achromatic overseer, and the environment stays DOM + tokens — the reference's factory floor is a mood board for surface.* values, not a backdrop to paint.
Decision. A. Everything in §07 is built on it. B stays documented as the upgrade path — C when there is an artist, with A derived from B by the trace pipeline. The sprites shown here are the reference itself, recolored to prove the mechanism — they are not shippable assets.

07bOutpost design: world + settlement

Hybrid: the world is a 16×16 quantized disc (the emblem, the only circle in the system); the settlement is a 1–4 unit mark on its horizon that encodes what the outpost is for, and the panel is the DOM body where hands and clearances live. 09Where the theme stops

THEMED
Object nouns · the five verbs (found, clear, open, enlist, commit) · rig + emblem · lane geometry · section eyebrows · empty-state titles
PLAIN, ALWAYS
Health words · run words (idle / working / done / failed) · read / write · timestamps, paths, shas · every error and validation message · toasts · tooltips (carry the plain word) · settings · docs · keyboard hints (⇧ not Shift)
NEVER
Fuel, HP, travel time, distance · lore in body copy · starfield parallax · scanlines · sound · working glow or breathe on anything not provably working · a tinted overseer · a hand rig used for the overseer or the hero rig used for a hand · a name you'd have to license
