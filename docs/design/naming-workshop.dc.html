OVERSEER · ROLE NOUN + PROPER NAME

Ship the role noun (Arbiter / Bridge / Assayer) as the fixed UI label and let the install set the proper name in the persona file — same as every other agent. Default proper name candidates: Meridian, Lodestar, Vesper. Reads as different via position (fixed center, no planet), its own 48×64 hero rig (spec §07), and a desaturated palette.
